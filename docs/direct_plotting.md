# ATLAS 直接绘图（v1.10.0）

## 工作流程

先用“数据清洗与良率汇总”处理根目录；有压缩包时先准备CSV，随后执行增量处理，
建立产品的 `.atlas/state.sqlite` 和各片清洗 CSV。
接着直接进入 BIN Map、Test Map 或 Probability，不再需要先运行 Merge BIN。

1. 左侧选择 LDO/DCDC/Load_switch 的父目录，点击“刷新索引”。
2. 选择分类、产品，展开 Lot，使用 Ctrl/Shift 多选 Lot 或 Wafer。
3. 右侧输入分析任务名称（例如“LOT001与LOT002低良对比”），点击“新建任务”；
   或从任务下拉框选择已有任务，恢复其最近一次预览的选片与参数。
   不手动新建时，首次预览会用名称框里的名称自动新建。
4. 选择测试项和绘图设置，点击“更新预览（不归档）”，在复用的图片窗口中查看。
5. 调整 Lot/Wafer、参考组、测试项、范围等，再更新预览。同一任务只保留一份当前草稿。
6. 满意后点击“保存高清版本”，先选择父目录，再输入便于记忆的文件夹名。
   默认父目录为产品的 `plots/bin`、`plots/test` 或 `plots/probability`，
   图片直接保存到“所选父目录/输入名称/”，不再额外嵌套任务目录或 `v001`。
   任一对话框取消都不保存；可用“打开目录”“查看图片”或“历史版本 / 恢复参数”查看结果。

三个页面共享根目录和明细缓存，但各自选片/绘图参数独立。
任务也按产品和图种隔离；改变 Lot 组合可以继续同一个任务，不需要另建任务。
名称输入框仅用于新建任务，不会重命名已有任务。任务目录名带短唯一编号，避免同名混淆。
一次只能选一个产品，可以跨多个 Lot；不同改版仍应采用独立产品记录。
左侧全选只选有效片；选中 Lot 时其中的灰色片不纳入绘图，数量和原因会提示。
可用片也可能有数量偏差、重复坐标等警告，绘图日志保留这些提示。

只使用自动增量处理登记的清洗结果。历史手动清洗 CSV/旧 Excel 不自动导入索引；
如尚未建缓存，先对该目录运行一次自动增量处理。绘图不会自行重清理原始数据。

## 状态与校验

- 可用：清洗结果、产品配置和输入文件集合与处理记录一致。
- 未处理：新 Wafer 尚未进入增量缓存。
- 待更新：配置、输入集合/文件时间或清洗结果变化；新增 RT 也属于此类。
- 缺失/失败/输入冲突：不能绘图，先恢复原始文件并完成增量处理。

刷新索引读取 SQLite 指标、文件名和大小/修改时间，不解析整个历史测试明细。
压缩包输入通过导入登记发现；待准备/变化/失败的包阻断所在Lot。人工忽略和同名副本
需要内容指纹确认；完整校验还会检查所选Lot的平铺CSV及仍在输入目录的压缩包。
已按确认操作移入备份的原包不再是必须存在的输入，不会阻断后续绘图。
点击预览或保存时再次检查配置、状态、输入集合和版本；渲染结束后再次检查。
缓存未命中时还校验清洗文件 SHA256。缓存命中通常复用大小/时间检查，不能发现
人为保留相同大小和修改时间的替换；勾选“完整校验选中片的文件内容”可检查选中片的
所有原始输入及清洗文件内容，代价是增加磁盘读取。其他产品/片不会完整校验。

请在复制文件完成后绘图，不要同时修改/增量重处理正在绘图的片。
发生版本变化时，不发布有效新草稿/新版本；原来已完成的草稿和保存版本保留。

## 概率分布图

- 默认每片 Wafer 一条曲线，保持原算法及绘图方式；图例使用完整产品/Lot/Wafer 身份，不推断 CP/FT。
- 左侧可设置参考组/分析组；右侧可选择高亮对象，或一键选中分析组高亮。
- 参考组只是对比标签，不自动认定为统计基线，不排除任何测试值。
- 可选择按 Lot 合并 die 分布，同 Lot 的参考/分析组分别成曲线。这是各片实际有效测试值
  的集合，不是各片均值的分布，也不是等片数加权；会隐藏片间差异。
- “自动规格”“锁定规格”“手动范围”可以同时勾选，至少选一种。
  自动规格沿用原自动缩放，绘出的规格线也参与范围；锁定规格仍沿用原程序的上下限加边距算法。
  缺少有效双边规格时，锁定模式沿用原行为回退自动范围，并在日志提示，不会编造规格。
  勾选手动范围时必须填写有限的 `min,max`，且 `min < max`。
- 各范围分别生成图片和 2×2 拼图，不将不同范围混在同一拼图中。
  保留数据点大小和部分高亮；多范围共用同一份排序及概率计算结果。
- 不同单位或上下限的同名测试项会拆成规格组，不会混用某片的 Spec。
- 无效/非有限数值不参与分布；不根据 Good BIN 自动过滤，保持原数据范围。

## BIN Map 和 Test Map

- BIN Map 保留多彩、BIN1 绿/其他红、指定 BIN 高亮和选定模式拼接。
  `6,9` 是分别生成，`6+9` 是同图一起高亮。
- Test Map 保留自动 3σ、手动、USL/LSL、通过/失败和多模式拼接。
- 保留 Notch、单片图、整合图、默认/手动排序。
- 手动排序使用完整片名，例如 `WL111_LOT002_W01,WL111_LOT001_W01`。
  可指定部分所选片，其他片排在其后；误填/重复片名会提示。
- 测试项可列表多选，也可填写逗号分隔列名或起始列-结束列。手动表达式覆盖列表；
  完整测试项名称优先匹配，范围按处理记录保留的测试列顺序。
- 同坐标去重只在单片内部进行，不会把不同 Lot/Wafer 的 die 合起来去重。
- Map 使用有效数值坐标。RT 条件清理保留重复记录时，沿用原 Map 最后一条坐标绘制逻辑；
  数据统计口径仍按原程序，需结合日志的重复记录警告。
- Test Map 将不同单位/限值拆图，缺少某测试项或有效值的片会在日志中明确提示。
  沿用原 Test Map 对 `>`/`<` 标记的数值转换，概率图仍只接受直接可转换的数值。

## 性能与缓存

三个页面共用一个 256 MiB 上限的 LRU 明细缓存，按清洗文件版本和已读列复用。
一次任务把所需测试项一起读取；已读列可用于之后的 Test Map/概率图/BIN Map。
新增列只加载缺少的列，已有列不必重新解析；清洗文件版本变化时替换旧版本。
日志“读取CSV 16次、复用内存数据25次”表示实际执行了16次CSV列读取，
另有25次取数所需列已在内存，不必再读取CSV。它不是25个文件或25张图，
而是本次启动以来三个绘图页面共用服务的累计次数；同一文件补读新列可能多次读取。
显示的MiB是当前明细缓存占用，不包含所有图片和概率曲线缓存的内存。
超过容量的单片数据仍可绘图，但不长期缓存。关闭应用后缓存消失，不改变磁盘文件。
概率图另有 64 MiB 上限的 LRU 数值计算缓存，保留完整有效测试值的排序及原概率位置。
缓存键包含测试项、单位/上下限、分组和所有实际参与片的身份/清洗内容指纹。
例如先比较 Lot1+Lot2，再比较 Lot2+Lot3，Lot2 的曲线可以复用；Lot2 内选片变化、
数据更新或规格变化时不会误用旧曲线。按 Lot 分组仍合并全部有效 die，而不是平均各片曲线。
改变 X 轴范围、点大小或高亮无需重复计算相同曲线，但图片本身仍需重新渲染。
超容量曲线仍完整计算，只是不长期保留。关闭应用后两个缓存均消失。
“清空明细缓存”同时释放明细和概率计算缓存，不删除原始、清洗文件、图片或 SQLite。

缓存上限不等于整个进程内存上限：当前选中的明细副本、数值转换、概率排序及高分辨率
整合图也需要内存。大量 Lot/测试项建议分组绘图，不要一次生成整个产品历史所有图。
三个页面的 Matplotlib 渲染串行执行，以避免跨线程的全局绘图状态冲突；数据加载在后台，
不会在 UI 线程中读取大 CSV。重复更改色阶/范围可以命中数据缓存，但仍需重新渲染图片。

## 输出与追溯

```text
产品目录/
├── Lot/summary_cleaning_data/...
├── .atlas/
│   ├── state.sqlite
│   └── plot_drafts/<图种>/<任务编号>/current/   # 当前预览，90 DPI
└── plots/
    ├── bin/<自定义图片文件夹>/...
    ├── test/<自定义图片文件夹>/...
    └── probability/
        ├── Lot1与Lot2对比/...               # 默认父目录下的高清图片，300 DPI
        └── tasks/<时间_任务名_编号>/
            ├── task.json                   # 任务名称、最近预览选片/参数
            ├── latest.json                 # 最近保存版本及位置
            ├── saved_versions.json         # 自定义保存位置索引，不是图片副本
            └── v001/...                    # 旧版存档，保留兼容
```

`<图种>` 是 `bin`、`test` 或 `probability`。现有时间编号文件夹不会删除、搬迁或覆盖；
`tasks` 用于管理分析任务及其历史参数，不是新的GUI高清保存位置。
也可以选择产品目录之外的其他磁盘/文件夹；不允许把图片存到ATLAS Git仓库里。
自定义保存不改变预览路径或名称，不在任务目录另存一份永久高清副本。
旧脚本直接调用绘图 API、不指定保存位置时，原来的 `v001` 归档方式仍保留。

预览仅降低图片分辨率，仍使用全部有效数据；不会抽样、改变统计口径或只画 Good BIN。
保存从同一份输入重新绘制高清图，不是放大低清预览。高清 Map/多图拼接仍有计算和内存成本。
同一任务内，相同数据与参数再次保存到同一位置时直接复用；指定新的位置或名称时，
复制已保存的高清图片到新位置，不重新渲染。参数或数据变化时重新生成高清图片。
同名文件夹若存在且不是当前任务的相同结果，提示另取名称，不覆盖里面的资料。
历史列表显示文件夹名称和实际保存位置，兼容旧版本；手工搬走的导出文件夹不会显示在历史中。
预览/版本都有 `manifest.json`，记录选片、清洗 SHA256、参数、警告、任务/版本及输出文件指纹。
文件名会安全转义，原测试项名/片身份保留在图和清单中。

更新预览先在临时目录生成，成功后替换当前草稿；保存也完成后才发布版本目录。
更新失败不会删除原草稿；保存失败不会发布半成品版本。程序强制中断时可能残留临时目录，
这些目录不进入版本历史。手工修改草稿图片或放入未登记文件会阻止替换，不会静默删除。
请将需手工编辑的图片另存到其他位置。保存过的版本不会被后续预览/保存覆盖。

BIN Map的产品/Lot/Wafer信息位于晶圆上方，与Test Map标题布局一致；
过长的身份信息自动换行，不再占用晶圆内部位置。左上角原有良率/失效占比仍保留。

修改选片或参数后，保存按钮禁用，须先更新预览；新增 RT、重新清洗或配置变化也会触发校验。
历史列表显示版本、时间、Lot、片数、测试项、范围/模式及图片数。
“恢复选片与参数”只恢复到当前任务界面，更新预览后可另存新版本，不改历史文件。
若历史片已不可用，拒绝静默恢复部分片；若清洗内容已更新，日志提示使用当前数据重新预览。
重启程序后，刷新索引、选择产品和任务即可继续，恢复参数不自动开始耗时绘图。

原 Merge BIN 不再显示在main中，但模块保留为可选独立工具。原三个 Excel GUI 类与 `create_excel_ui(parent)`
也保留供旧脚本调用，主程序和模块独立运行默认使用直接绘图页面。
真实数据及全部输出仍须存放在 Git 仓库之外。验证使用临时合成数据，不提供生产性能保证。
